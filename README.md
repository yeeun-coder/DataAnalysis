# 데이터 분석 기말대체 프로젝트

## 1. 프로젝트 개요

본 프로젝트는 자유 주제를 선정하여 데이터를 수집하고, 전처리 및 탐색적 데이터 분석(EDA)을 수행한 후 머신러닝 기반 분석과 시각화를 통해 의미 있는 결과를 도출하는 데이터 분석 프로젝트이다.

### 프로젝트 진행 과정

1. 프로젝트 주제 선정
2. 데이터 준비
3. 데이터 전처리 및 탐색적 데이터 분석(EDA)
4. 데이터 분석 및 머신러닝 모델링
5. 데이터 시각화
6. 분석 결과 및 결론 도출

## 3. 프로젝트 필수 요구사항

### 3.1 프로젝트 범위

강의자료 6페이지의 빨간색 테두리 안에 포함된 항목을 프로젝트에 포함해야 한다.

- Python을 활용한 데이터 분석
- pandas를 활용한 데이터 가공 및 정제
- scikit-learn을 활용한 데이터 분석 및 머신러닝
- Matplotlib, seaborn, Tableau 등을 활용한 데이터 시각화
- 분석 결과 도출

### 3.2 머신러닝 알고리즘 적용

단순한 통계적 방법론만으로는 프로젝트를 수행할 수 없다.

**머신러닝 알고리즘을 최소 1가지 이상 적용해야 한다.**

강의자료에 제시된 알고리즘은 다음과 같다.

| 알고리즘 | 설명 |
|---|---|
| Decision Tree | 의사결정나무 |
| Random Forest | 랜덤 포레스트 |
| SVM | 서포트 벡터 머신 |
| Logistic Regression | 로지스틱 회귀 |
| AdaBoost | 에이다부스트 |
| XGBoost | 익스트림 그래디언트 부스팅 |
| LGBM | LightGBM |

- 강의 내용 이외의 머신러닝 알고리즘도 적용 가능하다.
- 머신러닝과 통계적 방법론을 함께 사용하는 것은 가능하다.
- 통계적 방법론만 사용하는 것은 불가능하다.

### 3.3 모델 평가 및 분석 결과

머신러닝 모델의 성능을 평가하고 분석 결과를 도출해야 한다.

평가 지표 예시:

- Accuracy (정확도)
- Precision (정밀도)
- Recall (재현율)
- RMSE (평균 제곱근 오차)

※ 문제 유형과 적용한 모델에 적합한 평가 지표를 선택한다.

주요 분석 결과에는 다음 내용을 포함하는 것이 좋다.

- 모델 성능 및 평가 결과
- 주요 영향 요인(Feature Importance)
- 중요 변수별 영향력 또는 계수
- 분석 결과 시각화
